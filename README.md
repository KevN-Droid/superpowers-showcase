# Superpowers Showcase

A curated showcase of **Superpowers** – an agentic skills framework and software development methodology.

It turns AI coding agents into disciplined developers by enforcing a structured workflow: brainstorm → plan → implement → review → test.

## Why it matters

Most agents jump straight to coding. Superpowers forces a thinking phase first, which dramatically reduces bugs and rework.

## The methodology

1. **Brainstorm** – Clarify the goal, constraints, and success criteria with the user.
2. **Plan** – Break the work into small, reviewable steps. Write the plan down.
3. **Implement** – Execute one step at a time. Commit after each.
4. **Review** – Self-review the diff against the plan. Fix issues.
5. **Test** – Run tests, add missing coverage, verify edge cases.
6. **Document** – Update README / docs only when behavior changed.

## Key skills included

- `brainstorm` – structured questioning before any code
- `plan` – decision-first planning with tradeoffs
- `implement` – step-by-step execution with checkpoints
- `review` – adversarial self-review
- `test` – test-driven verification
- `debug` – systematic root-cause analysis

## How to use

Install via your agent of choice (Claude Code, Codex, Cursor, Grok, OpenCode). The skills auto-activate on coding tasks or via slash commands like `/superpowers`.
