# Brainstorm Skill

Before writing any code, run this checklist:

1. **Restate the goal** in one sentence. Confirm with the user.
2. **List constraints**: performance, security, compatibility, time.
3. **Identify unknowns**: what do we not know yet?
4. **Propose 2-3 approaches** with pros and cons.
5. **Pick one** and get explicit approval.
6. **Only then** start planning the implementation.

Never skip to code. The best code is the code that solves the right problem.
